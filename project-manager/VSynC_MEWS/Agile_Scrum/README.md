# Agile / Scrum

Agile / Scrum practices were used to structure software delivery, prioritize work, coordinate iterations, and track progress across a broader hardware and software development program.

## Product Backlog

The project backlog was organized into high-level epics and progressively broken down into stories and tasks for execution and tracking.

| Priority | Epic | Item | Delivery Focus |
|---|---|---|---|
| P1 | Product | Core monitoring capability | Product delivery |
| P1 | Hardware | Wearable device development | Hardware |
| P1 | Software | Mobile and backend development | Software |
| P1 | Integration | Device, gateway, and cloud integration | Integration |
| P1 | Quality | Quality management and compliance | Quality |
| P1 | Validation | Verification and validation | V&V |
| P2 | Clinical | Clinical study preparation | Clinical |
| P2 | Regulatory | Safety and regulatory activities | Regulatory |
| P2 | Production | Production validation and readiness | Manufacturing |

## Delivery Planning

The backlog and project schedule were used together to manage dependencies, sequencing, milestones, and delivery coordination.

```text
Backlog
   ↓
Prioritization
   ↓
Sprint / Iteration Planning
   ↓
Development & Integration
   ↓
Review / Validation
   ↓
UAT / Release Readiness
```
