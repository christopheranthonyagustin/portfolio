Shopify Orders

Steps:
  1. Click Import Shopify Orders.
  2. Verify the imported orders in LogiVis.

Delivery Status

When: You need the latest shipment status now and don't want to wait for the scheduled update.

Steps:
  1. Click Bulk Update Delivery Status.
  2. Review the updated shipment statuses.

Download Multiple AWB

When: You need AWBs for multiple shipments.

Steps:
  1. Select 1–5 eligible shipments.
  2. Each shipment must have an SPX tracking number and must not be Unfulfilled.
  3. Click Download Multiple AWB.
  4. Review the consolidated PDF and use the PDF viewer's Download button.
