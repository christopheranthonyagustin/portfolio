## Important status warning

This package is a **working engineering baseline**, not a signed-off final architecture. It is grounded in the currently available Mindora diagrams, prior project decisions, and the established CareerOps baseline. The complete SRS v2.0 source document and the original approved Design Input/review record were not located as readable source documents during package preparation. The screen recordings were visually sampled; their audio was not fully transcribed. These items are explicitly listed as validation inputs.

Do not interpret a proposed architecture, unresolved decision, or inferred requirement as user-approved.
