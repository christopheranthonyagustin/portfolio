# WLocate Fleet Management Platform

## Enterprise Fleet Management, Infrastructure & Cloud Foundation

> **Duration:** 2014 – 2015 (Approx.)
>
> Enterprise Fleet Management System supporting real-time GPS tracking, dispatch operations, route optimization, fleet analytics, and enterprise infrastructure for transportation and logistics businesses.

---

## Project Overview

WLocate is an enterprise Fleet Management Platform designed to provide organizations with real-time vehicle tracking, fleet monitoring, route optimization, driver management, and operational reporting.

Beyond software development, this project provided my foundation in enterprise infrastructure administration and early cloud adoption. I was responsible for supporting both on-premises and cloud environments that hosted the platform throughout its software development lifecycle and production operations.

The platform evolved from dedicated on-premises infrastructure into Microsoft Windows Azure, while maintaining virtualized environments for Development, Testing, User Acceptance Testing (UAT), Staging, and disaster recovery.

---

# Business Challenges

The platform required a reliable infrastructure capable of supporting:

- Real-time GPS communication
- High transaction volumes
- Continuous vehicle tracking
- Multiple software development environments
- Customer deployments
- Business continuity
- High Availability (HA)
- Disaster Recovery (DR)

As customer demand increased, the infrastructure evolved from traditional on-premises servers into Microsoft Windows Azure while maintaining operational readiness through redundant environments.

---

# Solution

Designed, maintained, and supported the enterprise infrastructure that hosted the Fleet Management Platform throughout its lifecycle.

The solution consisted of dedicated Windows servers, Hyper-V virtualization, Microsoft SQL Server, IIS-hosted web applications, Windows Services, and Microsoft Windows Azure infrastructure supporting production operations.

The on-premises virtualized environment supported the Software Development Life Cycle (SDLC), providing isolated Development, Testing, UAT, and Staging environments while also serving as a contingency platform for production recovery when required.

## Virtualized Infrastructure

Using Microsoft Hyper-V, multiple virtual machines were created to support:

- Development
- Research & Development
- Testing
- User Acceptance Testing (UAT)
- Staging

This significantly improved resource utilization while allowing multiple isolated environments to run on shared hardware.

---

## Cloud Migration

As the platform expanded, production workloads transitioned from on-premises infrastructure to Microsoft Windows Azure.

Cloud infrastructure improvements included:

- Production hosting
- High Availability (HA)
- Redundant endpoints
- Backup environments
- Improved scalability
- Increased service availability

The virtualized on-premises infrastructure remained available for development, testing, staging, and business continuity purposes.
