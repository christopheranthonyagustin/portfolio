# Comfort Ambulance Job Dispatch System

## Enterprise Solution Deployment & Mobile Workforce Management

> **Duration:** 2017 (Approx.)
>
> Customer implementation of AceCom's Fleet Management System (FMS) for Comfort Ambulance, providing real-time ambulance dispatch, Mobile Data Terminal (MDT) integration, and cloud-hosted workforce management.

---

# Project Overview

Comfort Ambulance required a dedicated deployment of AceCom's Fleet Management System (FMS) to support ambulance dispatch operations, mobile workforce management, and real-time communication between dispatchers and field personnel.

Unlike a multi-tenant SaaS deployment, this implementation involved provisioning a dedicated customer environment, configuring the application, deploying supporting infrastructure, and customizing the solution to meet Comfort Ambulance's operational requirements.

The solution enabled dispatchers to assign emergency jobs through a centralized dispatch portal while ambulance drivers received and acknowledged assignments using Android-based Mobile Data Terminals (MDTs).

---

# Solution

Deployed a dedicated customer instance of AceCom's Fleet Management System (FMS) within Comfort Ambulance's environment.

The deployment included application installation, database configuration, environment setup, system configuration, Android MDT integration, and production deployment.

The solution consisted of:

- Dispatcher Web Portal
- Job Dispatch Management
- Android Mobile Data Terminal (MDT)
- GPS Tracking
- MySQL Database
- Web Services
- Cloud-hosted customer environment
