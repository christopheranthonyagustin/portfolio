# Paulo Security Portfolio

Personal professional portfolio website for **Ephraim Paulo Hernandez**, showcasing his experience in electronic security systems, surveillance, security infrastructure, systems integration, and technical operations.

This portfolio website was designed and developed by **Christopher Anthony Agustin (Anthony)** as a personal professional website for Paulo.

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

The website is designed for static deployment using Next.js.

Set `NEXT_PUBLIC_SITE_URL` to the final production URL before deployment so canonical and Open Graph URLs use the live website address.

## Gallery

Temporary gallery visuals are included in `public/gallery/`.

These can be replaced with Paulo's approved professional photographs using the existing filenames, or the image paths can be updated in:

```text
components/GallerySection.tsx
```
