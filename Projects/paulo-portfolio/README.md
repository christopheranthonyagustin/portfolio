# Paulo Security Portfolio

Personal portfolio for Ephraim Paulo Hernandez.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deployment

Set `NEXT_PUBLIC_SITE_URL` to the final production URL before deployment so canonical/Open Graph URLs use the live site.

## Gallery

Temporary gallery visuals are in `public/gallery/`. Replace them with Paulo's approved professional photographs using the same filenames, or update `components/GallerySection.tsx`.

The CV is `public/Hernandez_CV.pdf`.
